# Security

Please report security problems **privately**: on GitHub open the **Security** tab of this repository and choose
**Report a vulnerability**. Please don't open a public issue for them.

Only the latest release gets fixes – update with `docker compose pull && docker compose up -d`.

---

**Deutsch:** Sicherheitsprobleme bitte **vertraulich** melden – im Reiter **Security** dieses Repositorys auf
**Report a vulnerability**, nicht als öffentliches Issue. Behoben wird nur in der neuesten Version.
